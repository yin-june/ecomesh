# Troubleshooting

## PlatformIO / ESP-IDF "Target Not Found" Error

**Symptom:** 
When running `pio run` or attempting to build/upload the `hardware-hub` project, PlatformIO fails during the CMake configuration phase with the error:
`Error: Couldn't find the main target of the project!`

**Root Cause:**
The ESP-IDF CMake build system was completely ignoring the `src/` directory (where the main application code lives). Because no source files were registered for the main component, the `hardware-hub.elf` target was never generated by CMake, leaving PlatformIO unable to find it.

This was caused by two misconfigurations in the CMakeLists files:

1. **Overwriting `EXTRA_COMPONENT_DIRS`:**
   In `hardware-hub/CMakeLists.txt`, the variable `EXTRA_COMPONENT_DIRS` was being forcefully set:
   ```cmake
   # INCORRECT
   set(EXTRA_COMPONENT_DIRS "../components")
   ```
   PlatformIO automatically uses this variable in the background to inject the `src` folder into the ESP-IDF build as a component. By using `set()`, this injection was erased.
   
   **Fix:** Changed `set` to `list(APPEND)` so custom components are added without destroying PlatformIO's configuration:
   ```cmake
   # CORRECT
   list(APPEND EXTRA_COMPONENT_DIRS "../components")
   ```

2. **Improper Source File Globbing:**
   In `hardware-hub/src/CMakeLists.txt`, the file globbing was set to match all file types:
   ```cmake
   # INCORRECT
   FILE(GLOB_RECURSE app_sources ${CMAKE_SOURCE_DIR}/src/*.*)
   ```
   This caused CMake to attempt to compile configuration files (like `.yml` and `CMakeLists.txt`) as source code, which can cause silent failures or corrupt the component registration.
   
   **Fix:** Restricted the glob to only match valid C/C++ source files:
   ```cmake
   # CORRECT
   FILE(GLOB_RECURSE app_sources "*.c" "*.cpp")
   ```

**Resolution:**
After applying these fixes, the `.pio` cache directory was deleted to force a clean CMake configuration. Running `pio run` successfully registered the `src` component, built the `hardware-hub.elf` target, and allowed standard uploading.
